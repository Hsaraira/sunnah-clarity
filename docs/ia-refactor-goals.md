# SunnahClarity IA Refactor Goals

Non-negotiable findings from audit:
- Topics and FAQs currently blur together too much
- Header navigation is overloaded and will not scale
- Left sidebar shows too much global inventory and should become contextual
- "Tradition", "Scholars", and "The Scholarly Tradition" overlap and need clearer separation
- Footer navigation is inconsistent with homepage/topic structure
- "Daily Dhikr" currently sits in a route pattern that may not scale cleanly
- Need a cleaner beginner journey and stronger hub structure

What this refactor is about:
- information architecture
- content grouping
- taxonomy
- navigation
- discoverability
- scalability

What this refactor is NOT about:
- changing theology
- rewriting the actual religious positions
- making the site feel generic or corporate
- doing random visual redesign without structural reason
